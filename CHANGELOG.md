### Added
- 2026-07-03 — Project scaffold: folder structure, pipeline docs (`docs/`), PM directives TASK-001..013, ADR/report templates, project `CLAUDE.md`. No code yet.
- 2026-07-03 — TASK-001 Supabase schema: 5 migration files (`supabase/migrations/`) for `signal_snapshots`, `state_transitions`, `daily_outlook`, `outcome_labels` + enum types; typed pydantic models (`src/aeolus/storage/models.py`); ADR at `directives/adr/TASK-001_supabase-schema.md`. `system_status`/`market_state` enforced as structurally distinct Postgres enum types. Model-layer tests pass (16/16); DB-level DDL tests written, pending `TEST_DATABASE_URL`.
- 2026-07-03 — TASK-001 live DB verification: schema applied to the real (shared, Ares) Supabase project via SQL Editor; access pattern switched to `supabase-py` + anon key (RLS disabled), matching Ares convention — direct-Postgres/CLI approach wasn't available in this environment. New live test suite `tests/storage/test_supabase_integration.py` (8/8 pass) replaces the unusable psycopg-based one.
- 2026-07-03 — TASK-002 Dhan API v2 ingestion layer: `src/aeolus/ingestion/` — credentials loaded from the shared Supabase `api_keys` table (same external refresh daemon as Ares, no new secret scheme); NIFTY spot + current-month futures resolved dynamically against Dhan's live scrip master CSV (roll-aware); WebSocket live feed (spot LTP, futures LTP, 5-level depth via `Full` packets) with exponential-backoff reconnect; REST-polled option chain (OI/greeks/IV per strike) with 2-consecutive-short-read partial-response detection; elapsed-time heartbeat staleness tracker feeding `system_status` (OK/STALE/DISCONNECTED), fully decoupled from `market_state`. `futures_basis` (futures − spot) included per OPEN_DECISIONS #4. ADR at `directives/adr/TASK-002_dhan-ingestion.md`. Full test suite (36/36) includes live integration tests against real Supabase, the real Dhan scrip master, and — during live market hours — the real Dhan WebSocket + REST APIs end-to-end.
- 2026-07-03 — TASK-002 amendment: added `india_vix` to `IngestionSnapshot` (Dhan `IDX_I` segment, security_id 21 — same subscription path as spot) and `IngestionService.lot_size` (resolved from the scrip master's `SEM_LOT_UNITS`, session-scoped). Unblocks TASK-003 (volatility) and TASK-004 (gamma) ADRs, both of which had flagged these as missing from ingestion rather than working around it. No new segment, vendor, or dependency — both fields come from the same compact scrip master CSV `instruments.py` already parses. 37/37 tests passing.
- 2026-07-03 — TASK-003 volatility signals: `src/aeolus/signals/volatility.py` — four pure sub-signal functions (IV percentile/rank, IV-vs-RV spread, VIX level+ROC, expected-move-consumed ratio), all on the `SignalResult` contract (`src/aeolus/signals/contract.py`, shared by TASK-004..007). No I/O — all trailing history caller-supplied. `iv_rv_spread` redesigned before implementation per human field feedback: scored primarily on IV's own cycle-to-cycle trend (falling IV = NO-GO regardless of absolute level), not the static IV-vs-RV level. Interim reason-string templater at `src/aeolus/explain/reason.py`, signature-compatible with TASK-010. ADR at `directives/adr/TASK-003_volatility-signals.md`. 24 new tests (61/61 total), ruff/mypy clean. See `reports/debug/TASK-003_debug-report.md`, `reports/qa/TASK-003_qa-report.md`.
- 2026-07-03 — TASK-004 gamma signals: `src/aeolus/signals/gamma.py` — `gex_regime` (signed, dollar-scaled net GEX across the chain; dealer-long-gamma-on-calls/short-on-puts sign convention; magnitude normalized via shared `_percentile_rank`) and `spot_distance_from_flip` (interpolated zero-gamma flip strike, strike-domain proxy; magnitude-only, sign-independent distance scoring — near the flip is the pin/magnet NO-GO zone). `_clamp01` promoted from `volatility.py` into `signals/contract.py`, now shared. ADR at `directives/adr/TASK-004_gamma-signals.md`. 12 new tests (73/73 total), ruff/mypy clean. See `reports/debug/TASK-004_debug-report.md`, `reports/qa/TASK-004_qa-report.md`.
